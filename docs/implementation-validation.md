## 非機能・境界条件

- **NFR-01**：クリックから次の描画機会（requestAnimationFrame）まで、Chrome最大13.6ms、Edge最大12.9ms。DOM更新はいずれも5ms未満。1秒以内の状態変化開始を確認。会場の物理ディスプレイでの応答時間は未計測。
- **NFR-02**：通信を無効化した状態でfile://から起動し、予測・外出・配車・到着まで完走。
- **NFR-03**：予測配置後、配車・到着後の再読み込みで、INITIAL・0%・未割り当て・ログなしへリセット。
- **NFR-04**：約30秒で説明できる3操作の導線と「周辺配置・未割り当て」の文言を実装。初見の審査員役による理解確認は未実施のため、合格とは扱わない。
- **NFR-05**：Chrome・EdgeともHTTP(S)リクエスト0件、コンソールエラー0件、未処理例外0件。コードに外部API呼び出し・APIキー・位置情報/カレンダーの権限要求なし。
- 連打と合成クリックイベントでも順序を飛ばさず、ログは最終8件のみ。
- 車両移動の確認値は両ブラウザーで約1.60秒。transitionendを遮断しても1.75秒の代替タイマーで進行。
- 「動きを減らす」設定では移動演出を省略し進行。移動中に設定を切り替えた場合も停止しない。
- キーボードのEnter・Spaceから予測・外出・配車を実行。フォーカス表示を実装。
- 対象画面幅で横方向のはみ出しなし。3操作ボタンは44px以上の高さを確保し、予定・予測欄の内容がカード内に収まることを検証。

- Aさんの09:30予約、RESERVATION、スコア1.00。予測後は予約1件・予測1件・合計1.82・HIGH DEMAND。
